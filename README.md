# seaharness-presentation-script

Full Codex-class presentation pack: writing quality, template following, native evidence, pptxgenjs create and JSZip edit, then ppt_open(publish=true).

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/seaharness-presentation-script#v2.0.5 --skill seaharness-presentation-script
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill seaharness-presentation-script
```

## 内容

技能正文在 `skills/seaharness-presentation-script/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/seaharness-presentation-script/payload/`，不要反向同步。版本以 git tag 为准。
